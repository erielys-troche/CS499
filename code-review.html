A walkthrough of my three original projects and how I planned to enhance each one.

Open the video on Loom if it doesn't load here.

What I found in each project

  • Global Rain (Java): the fee amounts were hardcoded numbers scattered through if-else statements, there was no input validation, and there were no tests.
  • Course Planner (C++): the binary search tree was unbalanced, and there was no way to catch a circular prerequisite.
  • Database (MySQL): every query was typed by hand, and the report was built by pasting screenshots into Word.

A correction to the video

In the video I said the foreign key columns were not indexed. My own DESCRIBE output shows MySQL had already indexed them, so I changed the plan to index State, SKU, and Status instead. The video and my Milestone Four narrative do not fully match because of this.
