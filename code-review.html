What I planned to improve

  • Global Rain (Java): fee logic is hard-coded in subclasses, so adding a pet type means editing existing code.
  • Course Planner (C++): the plain binary search tree can degrade to O(n), and there's no check for circular prerequisites.
  • Database (MySQL): queries were typed by hand and the report was assembled manually. Correction: in the video I said the foreign key columns weren't indexed, but my DESCRIBE output shows MySQL had already indexed them (MUL). The enhancement indexes the columns I actually filter on instead.
